# AWS S3 Setup for File Storage

LaundryFlow uses Amazon S3 to store:
- User profile images
- QR Code archival
- Generated PDF invoices

## Configuration Steps

1. **Create an S3 Bucket**
   - Bucket name: `laundryflow-production-assets` (or similar)
   - Region: Same as your EC2 and RDS instances
   - **Block all public access** (Recommended). Files will be accessed securely via presigned URLs generated by the FastAPI backend.

2. **Set up IAM Role (EC2 Instance Profile)**
   Instead of using long-lived access keys, create an IAM Role:
   - Go to IAM > Roles > Create Role
   - Trusted entity: AWS service > EC2
   - Attach policies: Create an inline policy for least privilege access to the bucket.

   ```json
   {
       "Version": "2012-10-17",
       "Statement": [
           {
               "Effect": "Allow",
               "Action": [
                   "s3:PutObject",
                   "s3:GetObject",
                   "s3:DeleteObject"
               ],
               "Resource": "arn:aws:s3:::laundryflow-production-assets/*"
           }
       ]
   }
   ```
   - Attach this IAM Role to your EC2 instance in the AWS Console.

3. **Backend Integration**
   - The FastAPI backend uses `boto3` to generate presigned URLs for client uploads and downloads.
   - Update `.env`:
   ```env
   AWS_REGION=us-east-1
   AWS_S3_BUCKET=laundryflow-production-assets
   ```
